# LiveGift Studio Overlay

Public browser-source overlay for LiveGift Studio.

Top Gift:
- GitHub Pages path: `/overlay/top-gift/`
- Public fallback host: `https://raw.githack.com/isyitamar/livegift-overlay/main/overlay/top-gift/index.html`

The overlay receives realtime Top Gift state from the desktop app and renders the gift image, sender name, coin value, and gift name.
